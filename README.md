## さーもんの集い公式リポジトリ

**詳細**
SamonPowershellの安全性を確かめれるようにするのが目的で作られました。
Supportなどを受けたい場合は[**さーもんの集い公式ディスコードサーバー**](https://discord.gg/efe5fsS2JA)に
参加してください。

**⚠注意⚠**<br>
サイトのコードは共有しません。<br>
ソースコードはSamonPowershellだけです。<br>
ホームページは安全性をチェック、ボット確認のために認証をボット認証を採用しています。<br>
ホームページは詐欺などのコードなどを組み込んでいません。
ホームページでSamonPowerShellダウンロードしてもZIP爆弾などの、危ないものは入れてないので安心願います。
